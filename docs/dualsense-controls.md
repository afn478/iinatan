# DualSense Controls

iinatan's DualSense support is disabled by default. Enable **DualSense controller input** in the Advanced settings for the active profile. macOS may ask for Input Monitoring permission the first time it is enabled.

Controller input is active while the IINA window is in the foreground, iinatan is enabled, and the controller is connected.

## Controls

| Control | Action |
| --- | --- |
| D-pad Up / Down | Scroll the open dictionary popup or audio menu. |
| D-pad Left / Right | Move between dictionary entries when a popup is open; move between audio and export controls in the audio menu. |
| Left stick Up / Down | Smooth-scroll the open dictionary popup or audio menu. |
| Right stick | Move the active lookup across subtitle text: left/right between words and up/down between subtitle rows. |
| L1 | Seek to the previous subtitle. |
| R1 | Seek to the next subtitle. |
| Cross | Open the first lookup when no popup is open, select the most visible dictionary entry when a popup is open, or activate the focused audio-menu control. |
| Circle | Close the audio menu or dictionary popup; when neither is open, resume playback. |
| Square | Toggle playback pause and resume. |
| Triangle | Play the selected entry's audio; hold to open the audio-source menu. |
| L2 (hold) | Add the selected entry to Anki using the add-anyway action when it is available. |
| R2 (hold) | Add the selected entry to Anki using the primary add action when it is available. |

Holding Triangle, L2, or R2 shows a progress indicator. Releasing Triangle before the hold completes plays the selected entry's audio.
